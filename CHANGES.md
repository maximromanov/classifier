# What's new in the Book Classifier

Newest first. The dates are those of the releases.

## 2.04 — 2026-11-13

- Shorter, readable links that show the book or author and the view, for example `#b=0597IbnJawzi.TalbisIblis&t=text`.
- Links no longer carry the data version: a link without one refers to OpenITI release 2023.1.8.
- All older links still work and open the same view.
- The Cite dialog copies each citation, or all four formats at once, as Markdown.
- An “A” button between − and + returns the text to its default size.

## 2.03 — 2026-11-10

- An Arabic keyboard for the search box, adapted from Peter Verkinderen's Arabic Virtual Keyboard.
- A "What's new" page: this one.

## 2.02 — 2026-11-08

- The book's cover in the search panel, linking to the book.

## 2.01 — 2026-11-07

- New header band and icons.
- The app can be added to a phone's home screen.
- Dark mode.

## 2.0 — 2026-11-06

- Rebuilt to run entirely in the browser.
- Book and author profiles; rolling windows with chapter headers; entropy compared; similar books; guided tours, captions, citations, links.
- The data and the evaluations are the same as in version 1.
- Zenodo record: https://doi.org/10.5281/zenodo.23985062

## 1 — 2025

- The original R Shiny version on the EIS1600 server. Zenodo record: https://doi.org/10.5281/zenodo.15663089
